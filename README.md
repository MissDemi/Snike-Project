Snike-Project
🐍 Snake Game – JavaScript

📌 Descriere

Acest proiect reprezintă o implementare a jocului clasic Snake, realizată folosind **HTML, CSS și JavaScript**. Jocul include elemente interactive, un sistem de scor și mecanici suplimentare care cresc dificultatea.

🎮 Funcționalități

* 🐍 Controlul șarpelui cu tastele săgeți
* 🍎 Măr normal → crește scorul și lungimea
* ⚡ Speed Apple → crește viteza jocului
* 🍀 Lucky Apple → condiție de câștig
* 💥 Detectare coliziuni (pereți + corp)
* 📈 Sistem de scor și nivel de viteză
* 🎬 Tutorial interactiv la început

🧠 Tehnologii folosite

* **HTML** – structură
* **CSS** – design + animații
* **JavaScript** – logica jocului

⚙️ Cum rulezi proiectul

1. Clonează repository-ul
2. Deschide fișierul index.html
3. Joacă 🎮

🎯 Cum se joacă

* Folosește tastele ↑ ↓ ← → pentru a controla șarpele
* Mănâncă mere pentru a crește
* Evită pereții și propriul corp
* Colectează **Lucky Apple** pentru a câștiga

🚀 Posibile îmbunătățiri

* salvare scor (highscore)
* nivele de dificultate
* sunete și efecte audio
* design îmbunătățit
